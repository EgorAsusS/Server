# Server

Приложения для клиента и сервера.

Сервер - работает как эхо-сервер: получает сообщение, добавляет к нему '!', и возвращает обратно
(если конец буффера для пересылки, то ничего не добавляет и отсылает обратно).

Клиент - отправляет сообщение ("!"), и ждет его обратно.

Программа клиент заканчивается, когда одно из приложений закрывается (т.е. закрывается сокет клиента или сервера)
Программа сервер заканчивается, когда оно закырвается (т.е. закрывается сокет сервера). При закрытии клиента, сервер закрывает сокет с ним и продолжает слушать

Клиент и сервер (в разных реализациях) получают конфигурации из файла с расширением .cfg (название файла указывается аргументом при запуске программы),
или как аргументы программы (IP (пробел) порт)
